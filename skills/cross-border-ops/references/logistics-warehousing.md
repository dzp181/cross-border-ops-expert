# 物流与仓配：头程、备货与两头预案

## 一、头程方式对照

> 价格为市场参考区间（2026 年常见报价带），实际以货代当期报价为准；重量体积、品类（带电/带磁/液体）会显著影响价格。

| 方式 | 时效（门到门） | 成本水平 | 起运量 | 适合 |
|---|---|---|---|---|
| 海运整柜 FCL | 25–40 天 | 最低 | 15–20 CBM 起 | 大批量、成熟爆款 |
| 海运拼箱 LCL | 30–45 天 | 低 | 1 CBM 起 | 中等批量、试单 |
| 铁路/卡航 | 18–30 天 | 中低 | 100 kg 起 | 欧洲内陆、旺季补货 |
| 空运（普货/带电） | 5–10 天 | 中高 | 45 kg 起 | 紧急补货、高货值 |
| 国际快递（DHL/UPS/FedEx） | 3–7 天 | 高 | 无 | 样品、小批量、断货急救 |
| 专线小包 | 8–20 天 | 中 | 无 | 直发（FBM/独立站） |

**计费重量**：体积重 = 长×宽×高(cm)/6000（空运常见口径，海运按 CBM）。**抛货（体积重 > 实重）成本会翻倍，选品时必须算。**

## 二、头程成本的口径

单件头程成本 =
（运费 + 报关费 + 目的港杂费 + 清关税金 + 拖车/派送 + 保险）÷ 实际发运件数

**必须把"税金"和"杂费"摊进去**，只算海运费会低估 20%–40%。

## 三、备货模型

### 三个关键量

| 量 | 公式 | 说明 |
|---|---|---|
| 日均销量 | 近 30 天销量 / 30（去掉异常大单） | 新品用广告测算的单量 |
| 补货总周期 | 生产天数 + 头程天数 + 入仓上架天数 + 缓冲 | 旺季加 7–15 天 |
| 安全库存 | 日均销量 × 安全天数 | 安全天数按波动率取 15–30 天 |

### 补货点与补货量

```
补货点（库存降到这个数就下单）= 日均销量 ×（补货总周期 + 安全天数）
建议补货量 = 日均销量 ×（补货总周期 + 覆盖天数）− 在途 − 现有库存
再向上取整到 MOQ 与装箱数（carton）的整数倍
```

用 `scripts/cbcalc.py reorder` 算，别心算。

### 常见错误

- 只算头程不算生产周期，导致下单太晚
- 用旺季日销备淡季的货（或反之），库存结构错配
- 忽略 MOQ 与装箱数，补 480 件实际要订 500 件，成本核算全错
- 忘记平台入库限制，货到了却约不到仓

## 四、仓配模式选择

| 模式 | 优点 | 缺点 | 适合 |
|---|---|---|---|
| 平台仓（FBA 等） | 流量倾斜、时效好、转化高 | 费用高、限制多、滞销罚金 | 主力爆款 |
| 第三方海外仓 | 灵活、可做一件代发/中转/FBA 预处理 | 需自建库存管理 | 多平台、大件、需贴标换标 |
| 国内直发 | 无库存压力 | 时效差、转化低、退货难 | 测款、长尾、定制 |
| 海外仓 + 平台仓组合 | 主仓备货 + 边仓调峰 | 管理复杂 | 月销稳定、旺季冲量 |

**FBA 与海外仓的分工口诀**：FBA 负责"卖得快的"，海外仓负责"补得快和退得回"。

## 五、断货预案

| 情况 | 动作 |
|---|---|
| 库存 < 30 天销量 | 立即下补货单，同时评估空运/快递补 20%–30% 救急 |
| 库存 < 15 天销量 | 涨价 5%–10% 降速、暂停部分广告、优先保核心词位置 |
| 已断货 | 链接保持可售（预售）或转 FBM 顶着，避免 listing 权重归零；断货超 30 天考虑重建链接 |
| 断货后恢复 | 前 7 天加大广告与优惠券，把排名拉回来 |

**断货是链接的隐形杀手**：权重恢复通常需要 2–4 周和额外广告投入，损失往往大于空运的差价。

## 六、滞销预案

| 情况 | 动作 | 底线 |
|---|---|---|
| 库龄 60–90 天 | 降价 5%–10% + 优惠券，加广告清 | 保住毛利 |
| 库龄 90–180 天 | 捆绑销售、站外折扣、秒杀 | 保本或微亏 |
| 库龄 > 180 天 | 清仓价、批量转批发、捐赠抵税（视税制） | 回笼现金，避免长期仓储费 |
| 完全卖不动 | 拆解取回残值或弃置 | 停止继续支付仓储费 |

**滞销的决策点不是"还能不能赚"，而是"继续持有成本 vs 立刻清掉损失"。** 长期仓储费会把利润吃穿。

## 七、包装与合规标签

| 项目 | 要求 |
|---|---|
| 外箱 | 抗压测试、唛头（SKU/数量/毛净重/产地） |
| 产品标签 | 品牌、型号、产地、成分/材质、警示语（按目的国语言） |
| 认证标识 | CE/UKCA/FCC 等标识位置与尺寸有规定，不能随便印 |
| 电池 | UN38.3 + MSDS + 电池标签，走带电渠道 |
| 食品接触 | 需符合 FDA 21 CFR / LFGB 等，附检测报告 |
| 儿童产品 | 年龄警示、CPC 证书（美国）、EN71（欧盟） |

## 八、清关单据清单

**通用**：商业发票（Commercial Invoice）、装箱单（Packing List）、提单/运单、报关委托书

**视情况**：原产地证（CO/Form A）、CE/FDA 等合规声明、VAT/EORI 号（欧盟）、进口商信息、产品检测报告

**常见扣关原因**：低报货值、品名与实物不符、缺认证、木质包装无熏蒸、电池未申报、收货人无进口资质

## 九、物流成本优化顺序

1. 减体积（改包装结构，抛货变实重，省最多）
2. 提高装箱率（减少空抛、加固但不加厚）
3. 换运输方式组合（海运为主 + 空运救急）
4. 谈货代月结与阶梯价（有量才有价）
5. 海外仓批量入仓替代多次小批（摊薄头程单位成本）

**不要**为了省运费而低报货值或改品名——罚款与扣货损失远超省下的钱。
