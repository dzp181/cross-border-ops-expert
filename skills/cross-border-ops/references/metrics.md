# 指标口径、诊断树与团队分工

## 一、指标口径表（回答时必须统一）

| 指标 | 公式 | 看什么 | 常见误读 |
|---|---|---|---|
| 曝光量 | 展现次数 | 流量池大小 | 曝光涨不代表卖得好 |
| 点击率 CTR | 点击 / 曝光 | 主图、价格、标题相关性 | 用全店 CTR 判断单品，错 |
| 转化率 CVR | 订单数 / 访问量（或点击） | 详情页承接力 | 分母用曝光算，数字会失真 |
| 客单价 AOV | 销售额 / 订单数 | 组合销售效果 | 与件均价混用 |
| ACOS | 广告花费 / 广告销售额 | 单条广告效率 | 只看 ACOS 会误杀新品 |
| TACOS | 广告花费 / 全店销售额 | 真实获客成本 | 忽视 TACOS 会以为在增长其实在亏 |
| 毛利率 | （售价 − 采购 − 头程 − 仓配）/ 售价 | 产品本身赚不赚钱 | 忘了头程，毛利虚高 |
| 净利率 | 扣完所有费用后 / 售价 | 真实赚钱能力 | 不算退货与税，净利虚高 |
| 库存周转天数 | 平均库存 / 日均销量 | 资金效率 | 只看周转不看库龄结构 |
| 退货率 | 退货件数 / 发出件数 | 产品与描述一致性 | 与"退款率"混用 |
| 回款周期 | 生产 + 头程 + 销售 + 结算 | 现金流压力 | 只算平台结算周期 |

## 二、诊断树：从结果倒推原因

### 场景 1：销售额下滑

```
销售额 ↓
├── 曝光 ↓
│   ├── 排名掉 → 查：差评、断货、绩效、竞品降价
│   ├── 广告预算/竞价降 → 查后台
│   └── 类目需求季节性 → 查去年同期
├── CTR ↓
│   ├── 主图被竞品比下去 → 看搜索结果同页
│   ├── 价格劣势 → 比价
│   └── 评分下降 → 查近期差评
└── CVR ↓
    ├── 详情页改动 → 回滚对比
    ├── 差评集中 → 聚类归因
    ├── 竞品上新/降价 → 竞品监控
    └── 配送时效变长 → 查库存与仓
```

### 场景 2：有流量不出单

1. 先看 CTR：CTR 正常 → 问题在页面；CTR 也低 → 问题在主图/价格
2. 页面问题按顺序查：价格差 > 10%？评分 < 4.2？主图弱？五点没讲清？运费/时效劣势？
3. 排除页面后，查流量精准度：广告词是否跑偏（搜索词报告）

### 场景 3：ACOS 持续走高

见 `ads.md` 五层排查。**先排除"页面转化下降"这个伪广告问题。**

### 场景 4：利润被吃掉

按占比从大到小排：采购 → 头程 → 平台费 → 广告 → 退货 → 仓储 → 支付/汇损。**逐项对比三个月前，找出涨幅最大的那一项。**

## 三、月度复盘框架

| 模块 | 看什么 | 输出 |
|---|---|---|
| 结果 | GMV、净利、净利率、订单数 | 与目标、上月对比 |
| 流量 | 曝光、CTR、自然/广告占比 | 流量结构是否健康 |
| 转化 | CVR、AOV、退货率 | 页面与产品问题清单 |
| 效率 | ACOS、TACOS、CPC | 投放调整清单 |
| 库存 | 周转天数、库龄结构、断货 SKU 数 | 补货与清库动作 |
| 现金 | 回款周期、可用现金 | 备货预算上限 |
| 组织 | 各岗位 KPI 达成 | 下月分工调整 |

**复盘只输出三样东西**：做对了什么（要复制）、做错了什么（要停）、下月三个最重要的动作（要有人负责）。

## 四、团队分工与 KPI

| 岗位 | 职责 | KPI | 常见错误 |
|---|---|---|---|
| 运营（店长） | 整体节奏、定价、库存决策 | 净利率、库存周转 | 只盯销售额 |
| 选品 | 找品、验证、供应链对接 | 新品成活率（3 个月内正向净利） | 只找爆款不管供应链 |
| Listing/内容 | 图片、文案、视频、A+ | CTR、CVR | 追求好看不管转化 |
| 广告 | 投放结构、预算、否词 | ACOS/TACOS、广告带来自然排名提升 | 只降 ACOS 不管单量 |
| 供应链/物流 | 备货、头程、入仓 | 断货率、滞销率、头程单件成本 | 只保不断货，不管滞销 |
| 客服 | 售前售后、差评处理 | 响应时效、差评率、退货挽回率 | 只会道歉不会改品 |

**小团队（3 人以内）合并方式**：运营兼选品，内容兼广告，供应链兼客服。但**决策权必须明确到一个人**，否则定价和备货会互相推翻。

## 五、周会与月度节奏

| 频率 | 议题 | 时长 |
|---|---|---|
| 每日 | 订单异常、库存告警、广告超支 | 10 分钟 |
| 每周 | 搜索词清理、竞品价格、断货风险 | 30 分钟 |
| 每月 | 全量复盘（按上表框架） | 90 分钟 |
| 每季 | 品类结构、供应链评估、平台策略 | 半天 |

## 六、数据来源

| 数据 | 来源 | 可信度 |
|---|---|---|
| 销量、广告、库存、退货 | 平台后台报表（最权威） | 高 |
| 类目排名、竞品销量估算 | 第三方工具（Helium10/Jungle Scout/卖家精灵等） | 中，只作区间参考 |
| 搜索量 | 平台搜索词报告 + 第三方关键词工具 | 中，趋势可用，绝对值不可信 |
| 行业大盘 | Marketplace Pulse、平台官方报告 | 中 |
| 政策与费率 | 平台政策页、官方公告 | 高（必须以此为准） |

**纪律**：结论可以用第三方数据做方向，但**金额类结论必须用后台真实数据**。
