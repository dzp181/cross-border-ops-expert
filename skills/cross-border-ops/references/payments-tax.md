# 收款、结汇与税务合规

> 本文件只讲**规则与路径**，不做税务筹划建议。具体申报与筹划请找持牌税务师/会计师。所有税率、免税额、政策口径均为参考，执行前必须以官方公告复核（近两年相关规则调整频繁）。

## 一、收款路径的四种形态

| 形态 | 代表 | 到账周期 | 费率参考 | 适合 |
|---|---|---|---|---|
| 平台自身结算 | Amazon 每 14 天结算、TikTok Shop 按平台规则 | 7–14 天循环 | 含在平台费里 | 单一平台起步期 |
| 第三方收款机构 | Payoneer、Airwallex、PingPong、LianLian、WorldFirst 等 | 1–3 个工作日 | 0.3%–1%（视通道与币种） | 多平台、多币种 |
| 境外主体账户 | 香港/美国/新加坡公司 + 当地银行 | 1–5 个工作日 | 电汇费 + 汇损 | 规模化、需本地主体（本地店/独立站） |
| 境内出口收款 | 通过具备资质的支付机构办理货物贸易收结汇 | 视通道 | 视通道 | 有进出口权、走 9710/9810 等模式 |

### 选择逻辑
1. 先看**平台是否支持**（部分平台只支持特定收款方式）
2. 再看**币种与汇损**（多币种收款能省 0.5%–1.5% 汇损）
3. 再看**主体匹配**（收款主体、平台注册主体、报关主体尽量一致，减少审核卡点）
4. 最后看**费率与到账速度**

### 常见卡点
- 收款账户名与店铺主体名不一致 → 平台审核不通过或资金冻结
- 用个人账户收货款 → 无法解释来源，结汇与申报都受限
- 多店铺共用一个收款账户 → 触发关联
- 收款机构要求提供贸易背景材料（订单、物流单、发票），平时就要留存

## 二、结汇的合规边界（必须讲清，不能含糊）

| 要点 | 说明 |
|---|---|
| 货物贸易收结汇 | 应与真实出口贸易背景匹配，具备合同/订单、物流单据、发票等证明材料 |
| 个人年度便利化额度 | 个人结汇有年度便利化额度（等值 5 万美元口径），**超出或用于经营性收款的，不能靠拆分规避** |
| 跨境电商报关模式 | 9610（零售出口）、9710（B2B 直接出口）、9810（出口海外仓）、1210（保税）——不同模式对应不同单证与退税路径 |
| 出口退税 | 需有进出口权、增值税专用发票、报关单、收汇凭证；小包直发通常无法退税，这是隐性成本 |
| 禁止 | 地下钱庄、对敲、虚假贸易、拆单分拆、借用他人额度 |

**给用户的实话**：小规模卖家常常"算上无法退税 + 汇损 + 收款费"，实际到手比账面少 3%–8%。做利润测算时必须把这块算进去。

## 三、VAT / 销售税：什么时候必须注册

### 欧盟

| 情形 | 义务 |
|---|---|
| 使用本地仓/平台仓（FBA、海外仓） | 有库存所在国即需注册该国 VAT，无门槛 |
| 从境外直发 B2C，货值 ≤ 150 EUR | 可用 IOSS 简化申报（在进口环节免增值税，由平台或卖家代收代缴） |
| 跨境远程销售超过目的国阈值 | 需在目的国注册（欧盟已推行统一阈值规则，具体以现行法规为准） |
| 平台代扣代缴 | 多数平台对非欧盟卖家实行代扣代缴，但**代扣不等于免注册**，申报义务仍在卖家 |

**申报节奏**：通常按月或按季，逾期有罚金与利息；连续不合规可能导致平台限制销售。

### 英国
- 有库存即需注册 VAT；平台对海外卖家多实行代扣代缴
- 需保留进口记录，进口 VAT 可抵扣

### 美国
- 无联邦 VAT；各州销售税（Sales Tax）由平台作为 Marketplace Facilitator 代收代缴为主
- 自有独立站需按各州经济关联（Economic Nexus）判断注册义务，阈值各州不同

### 日本 / 澳洲 / 加拿大
- 日本 JCT、澳洲 GST（低值进口商品由平台代收）、加拿大 GST/HST——均有低值货物代收机制，需按现行规则核对

## 四、EPR（生产者责任延伸）

| 国家 | 常见类别 | 触发条件 |
|---|---|---|
| 德国 | 包装法（VerpackG）、电子电器（WEEE）、电池法 | 向德国销售带包装商品即需包装注册（LUCID） |
| 法国 | 包装、电子、电池、纺织品、家具等 | 需注册 UIN 并提供回收贡献费 |
| 意大利/西班牙 | 包装、电子 | 类似机制，逐步收紧 |

**平台会校验 EPR 注册号**，缺失会直接限制该国销售。这是"没注册就卖不了"，不是"以后再说"。

## 五、关税与进口税

| 市场 | 起征/免税口径（参考，需复核） | 说明 |
|---|---|---|
| 欧盟 | 货值 ≤ 150 EUR 免关税（增值税另计） | 关税按 HS Code 与申报货值计 |
| 美国 | 曾有 800 USD 免税额度，**近两年对特定来源小包政策多次调整，执行前必须核实最新状态** | 不能按旧规则报价 |
| 英国 | 货值 ≤ 135 GBP 有简化安排 | 增值税由平台或卖家代收 |

**HS Code 归类错误是常见风险**：归类错 → 税率错 → 补税 + 罚金 + 扣货。不确定时找报关行确认，不要自己猜。

## 六、现金流：跨境生意的真实杀手

```
现金占用 = 备货货款 + 在途库存 + 平台待结算 + 广告预付
回款周期 ≈ 生产天数 + 头程天数 + 销售周转天数 + 平台结算天数
```

用 `cbcalc.py cash` 算缺口。

**经验值**：月销 10 万美元的店，通常需要 25–40 万美元的周转资金才能不卡壳。很多卖家不是不赚钱，是钱都变成了库存和在途。

### 现金流三条纪律
1. 备货预算不超过可动用资金的 60%，留 40% 应对补货与广告
2. 旺季前 3 个月开始备现金，不要靠旺季销售回款去备旺季货
3. 每周看一次"可用现金 / 未来 30 天应付"，而不是只看利润表

## 七、回答这类问题时的纪律

- 说清是**注册义务**还是**申报节奏**，不要混着讲
- 税率与阈值一律标"参考，需按现行法规复核"
- 明确区分"平台代扣代缴"与"卖家免申报义务"——这是两件不同的事
- 不做"零申报""拆单""借额度"这类建议，明确说风险
