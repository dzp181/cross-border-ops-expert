# 平台规则、入驻路径与处罚类型

> 口径截至 2026-10，平台政策与费率变动频繁。**执行前必须以卖家后台公告或官网政策页复核**，本文件只提供结构与方法，不替代官方文本。

## 一、主流平台定位对照

| 平台 | 模式 | 适合谁 | 核心门槛 | 运营重心 |
|---|---|---|---|---|
| Amazon | 自运营（FBA / FBM） | 有供应链与资金、能做品牌与合规 | 产品合规、账号绩效、广告能力 | Listing 转化 + 广告效率 + 库存周转 |
| TikTok Shop | 跨境店 / 本地店 / 全托管 | 有内容与达人资源 | 内容产能、达人建联、发货时效 | 短视频/直播 + 达人联盟 + 爆品节奏 |
| Temu | 全托管 / 半托管 / 本地仓 | 工厂型、价格与产能优势 | 极致成本、快速供货 | 报价竞价 + 供货稳定 + 款型更新 |
| Shopee | 跨境（SLS）/ 本地店 | 东南亚方向、中小卖家 | 上新速度、店铺评分 | 铺货 + 活动报名 + 低价引流 |
| AliExpress | 全托管 / 半托管 / 自运营 | 想试水多国、SKU 多 | 类目资质、物流时效 | 选品宽度 + 物流时效 |
| 独立站（Shopify 等） | DTC 自建 | 有品牌与投放能力 | 流量获取、支付成功率、信任建设 | 素材 + 落地页 + 支付风控 + 复购 |

**选平台的判断顺序**：供应链优势在哪 → 内容能力有没有 → 能承受多长回款周期 → 团队能同时运营几个平台（小团队不超过 2 个）。

## 二、Amazon 运营规则要点

### 账号绩效（长期沿用口径，具体阈值以各站点后台为准）

| 指标 | 常见红线 | 说明 |
|---|---|---|
| 订单缺陷率 ODR | < 1% | 差评 + 索赔 + 信用卡拒付 |
| 订单取消率 | < 2.5% | 卖家原因取消 |
| 迟发率 | < 4% | 超出承诺发货时间 |
| 有效追踪率 | > 95% | 有真实可查单号 |
| 回复时效 | 24 小时内 | 买家消息 |

### 物流与费用结构

- **FBA**：平台代仓代发，费用由"配送费（按尺寸重量分段）+ 月度仓储费 + 长期仓储/低库存费"构成；旺季有附加费。**费率表每季度可能调整，必须查当期费率卡。**
- **FBM**：自发货，需满足配送时效承诺，跨境直发要保证有效追踪。
- **入库限制**：新账号与部分类目有库存容量/入仓数量限制，旺季前会收紧。

### 常见处罚与后果

| 类型 | 触发原因 | 后果 | 应对方向 |
|---|---|---|---|
| Listing 下架 | 类目审核缺失、图片违规、描述夸大、关键词堆砌 | 链接不可售 | 按通知逐项整改后申诉 |
| 销售权限移除 | 认证缺失、产品安全投诉 | 该类目禁售 | 补认证与检测报告 |
| 账号冻结/审核 | 绩效严重不达标、关联、侵权累计 | 资金预留 90 天以上 | 提交 POA（根因-措施-预防） |
| 侵权投诉 | 商标/专利/版权/外观 | 链接下架、资金扣留 | 取得授权或反通知（需谨慎） |

### POA（行动计划）结构

1. **根因**：具体到机制，不写"我们疏忽了"这种空话
2. **已采取的措施**：逐条对应根因，附证据（截图、单号、检测报告）
3. **预防机制**：SOP、责任人、检查频率
4. **不要**：甩锅平台、承诺"以后一定注意"、一次申诉塞进多个不相关问题

## 三、TikTok Shop 规则要点

- **店铺类型**：跨境店（从国内发货，时效压力大）/ 本地店（需当地主体与本地仓）/ 全托管（平台定价与履约）
- **流量结构**：短视频挂车 → 直播 → 达人联盟（Affiliate）→ 商城搜索。**达人分销是跨境店最快起量的路径**，但要提前设好佣金率与样品成本
- **履约红线**：发货时效与揽收时效是店铺评分核心，超时直接影响流量
- **内容合规**：功效宣称（美妆/保健）、对比测评、真人出镜授权、音乐版权，违规会限流或下架

## 四、Temu 规则要点

| 模式 | 谁负责定价 | 谁负责履约 | 卖家要做什么 |
|---|---|---|---|
| 全托管 | 平台 | 平台（国内集货仓） | 供货报价、备货到仓、款式更新 |
| 半托管 | 卖家 | 卖家（海外仓发货） | 定价与备货、海外仓履约 |
| 本地仓/Y2 | 卖家 | 卖家 | 本地库存与配送时效 |

- 核心机制是**报价竞价**：同款比价，价高者被替换。利润来自成本控制与款型差异，不来自运营技巧
- 备货要求严格：断货、延迟到仓会被扣罚或降权
- 半托管适合已有海外仓、想做高客单或大件的卖家

## 五、Shopee / AliExpress 要点

- **Shopee**：SLS 跨境物流是主干，店铺评分（发货、回复、差评）决定流量倾斜；活动报名（闪购/大促）是主要放量手段
- **AliExpress**：全托管重供货能力，半托管重本地履约；自运营重选品宽度与物流时效

## 六、独立站要点

| 环节 | 关键指标 | 常见卡点 |
|---|---|---|
| 流量 | CPM、CTR、CPC | 素材同质化、受众过宽 |
| 落地页 | 加购率、结账率 | 加载慢、信任元素缺失、运费不透明 |
| 支付 | 支付成功率 | 风控拒付、不支持本地支付方式 |
| 履约 | 妥投时效、纠纷率 | 承诺时效不实、物流轨迹断档 |
| 复购 | 30/60 天复购率 | 无邮件/短信触达、无会员机制 |

## 七、入驻材料通用清单

**必需**：营业执照（经营范围含相关货物销售/进出口）、法人身份证、对公账户、品牌授权或商标受理书（品牌类目）、产品资质（按类目）、收款账户

**视情况**：进出口权、境外主体（本地店/独立站）、VAT 税号（EU/UK）、EPR 注册号（德法等）、检测报告（CE/FCC/FDA 等）

**不适用**：与所申类目无关的资质不要硬塞，会拉长审核

## 八、账号风控：关联的常见触发因素

| 维度 | 具体表现 |
|---|---|
| 网络 | 同一 IP/网段、公共 VPN 出口、频繁切换地区 |
| 设备 | 同一电脑/浏览器指纹、同一手机 |
| 资金 | 同一收款账户、同一银行卡 |
| 资料 | 同一地址、同一电话、同一法人交叉 |
| 行为 | 多账号互刷、同步上下架、异常登录时间 |

合规做法：一店一环境一收款，人员权责分离，不用公共网络登录后台。**不要试图用工具"规避关联"，这是明确违规。**
