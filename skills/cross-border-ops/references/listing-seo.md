# Listing 与关键词：让流量能被接住

## 一、转化漏斗的四个断点

```
曝光 → 点击 → 加购/下单 → 好评/复购
        │        │            │
    主图/价格  详情/评论/运费   产品与服务
```

**诊断原则：哪一层断了只治那一层。** 点击率低改主图和价格，转化率低改详情和评论，复购低改产品本身。

| 指标 | 参考基准（常温类目） | 偏低先查 |
|---|---|---|
| 点击率 CTR | 0.4%–1.2% | 主图、价格、标题核心词是否对得上 |
| 转化率 CVR | 8%–20% | 五点、A+、评论数、评分、配送时效、运费 |
| 加购率 | 8%–15% | 图片信息完整度、款式选择 |
| 退货率 | < 8%（服装 15%+ 正常） | 尺寸描述、材质预期、图片失真 |

> 不同类目差异很大，基准值只用于"明显异常"的判断，不要当考核指标。

## 二、标题结构

**公式**：品牌 + 核心词 + 关键属性（材质/规格/数量）+ 场景/人群 + 差异点 + 兼容性

规则：
- 核心词放在前 5 个词内，移动端只显示前 60–70 字符
- 一个标题只主打一个核心词族，不要把三个不相关品类塞进去
- 不堆砌、不重复、不加"Best/Top/No.1"这类无法证实的词
- 大小写：实词首字母大写；不要全大写
- 数字与单位统一（inch/cm 不混用）

反面例子：`Hot Sale Best Quality Premium Multifunctional Portable Outdoor Camping Light Lamp Lantern USB Rechargeable Waterproof Super Bright 1000LM for Hiking Fishing Emergency`
问题：全是形容词堆砌，核心词不明确，无法被精准匹配。

正面例子：`Camping Lantern Rechargeable, 1000LM Waterproof LED Tent Light with 3 Modes, USB-C Powered, for Hiking Power Outage Emergency`

## 三、五点描述（Bullet Points）

每一行一个**用户利益 + 支撑证据**，不要写功能清单。

| 位置 | 写什么 | 结构 |
|---|---|---|
| 第 1 点 | 最大痛点 + 你的解决 | 痛点 → 方案 → 结果 |
| 第 2 点 | 核心功能（具体参数） | 参数 + 带来的好处 |
| 第 3 点 | 使用场景 | 谁在什么场景用 |
| 第 4 点 | 品质与安全 | 材质、认证、测试 |
| 第 5 点 | 售后与配件 | 保修、含什么、联系方式 |

写法要求：每点 150–200 字符；开头 3–5 个词大写做视觉锚点；不用感叹号堆情绪；不写平台禁止的保证性承诺（"永久保修""100% 治愈"）。

## 四、图片与视频

| 位置 | 内容 | 关键要求 |
|---|---|---|
| 主图 | 纯白底、产品占画面 85% | 无文字水印、无道具、无边框 |
| 图 2 | 核心卖点可视化 | 一张图说清最大差异 |
| 图 3 | 尺寸/规格标注 | 用对照物体现大小 |
| 图 4 | 使用场景 | 真人/真实场景优先 |
| 图 5 | 细节与材质特写 | 做工、接口、缝线 |
| 图 6 | 包装与配件清单 | 减少"少了东西"差评 |
| 图 7 | 对比图 | 与旧款/常见问题对比（不得贬损具体竞品） |
| 视频 | 15–30 秒 | 前 3 秒出现产品与核心用途 |

## 五、关键词分层与埋词

| 层级 | 来源 | 用途 | 埋在哪 |
|---|---|---|---|
| 核心词 | 类目主词、搜索量最大 | 标题前段 + 广告精准 | 标题、五点、Search Terms |
| 精准长尾 | 搜索词报告里"有点击有转化"的词 | 广告主力 | 五点、A+、Search Terms |
| 竞品词 | 竞品品牌/型号（注意商标风险） | 广告定投，不埋 Listing | 只用于广告 |
| 场景/人群词 | 使用场景、节日、人群 | 拓宽流量 | 五点、A+、后台属性 |
| 属性词 | 材质、尺寸、颜色、认证 | 提高相关性 | 标题、属性字段、Search Terms |

**埋词纪律**：
- Search Terms 不重复标题已出现的词，不写品牌名（除非自有），不写竞品名
- 后台所有属性字段填满（材质、用途、目标人群），属性也会被索引
- 一次只改一处，改完观察 7–14 天再动下一处，否则无法归因

## 六、差评归因表

| 差评关键词 | 真实原因 | 改哪里 |
|---|---|---|
| 尺寸不符 / 太小 | 图片比例或描述不实 | 加对照物图、改尺寸表 |
| 质量差 / 坏了 | 供应链批次问题 | 换供应商或加质检，不要只改文案 |
| 少了配件 | 包装漏装 | 装箱清单 + 出厂称重核对 |
| 不好用 / 复杂 | 说明书缺失 | 加图示说明卡、拍安装视频 |
| 有异味 | 材料或胶水 | 换料、增加晾置工序 |
| 物流慢 | 承诺时效不实 | 改配送模板，不要承诺做不到的时效 |

**差评的正确用法**：前 20 条差评按关键词聚类，占比最高的那一类是改产品的依据，不是改文案的依据。

## 七、上新后的动作节奏

| 时间 | 动作 |
|---|---|
| D0–D3 | 检查索引（核心词能否搜到自己的链接）、图片审核、类目是否放对 |
| D3–D7 | 开自动广告 + 1 组精准，收集真实搜索词 |
| D7–D14 | 看 CTR/CVR，CTR 低改主图，CVR 低改五点与价格 |
| D14–D21 | 用搜索词报告做否词，把出单词提到精准组 |
| D21–D30 | 判断是否值得加库存与追加投放，不达标就止损 |
