# 合规与风控：认证、知产、账号安全

## 一、认证矩阵（按品类查，不按感觉猜）

| 市场 | 认证/标识 | 适用品类 | 周期参考 |
|---|---|---|---|
| 欧盟 | CE（含 LVD/EMC/RED/MDR 等指令） | 电子电器、无线、机械、医疗 | 2–8 周 |
| 欧盟 | RoHS / REACH | 几乎所有带电与含化学品品类 | 1–3 周 |
| 欧盟 | EN71 / EN62115 | 玩具、儿童电动玩具 | 2–4 周 |
| 欧盟 | LFGB / 1935/2004 | 食品接触材料 | 2–6 周 |
| 欧盟 | WEEE / 电池指令 | 电子、电池 | 注册即可，配合 EPR |
| 英国 | UKCA | 同 CE 范围（英国市场） | 2–8 周 |
| 美国 | FCC（SDoC/ID） | 无线、含射频电子产品 | 2–4 周 |
| 美国 | FDA（食品接触/化妆品/器械） | 相关品类 | 4–12 周（器械更长） |
| 美国 | CPC + CPSC 测试 | 12 岁以下儿童产品 | 2–4 周 |
| 美国 | 加州 65 号提案警示 | 含铅/邻苯等化学物质 | 标签合规 |
| 全球运输 | UN38.3 + MSDS + 危包证 | 锂电池、含电池产品 | 2–6 周 |
| 日本 | PSE（菱形/圆形）、技适 | 电器、无线 | 4–8 周 |

**判断口诀**：先查目的国 + 品类，再看平台是否要求上传证书。**平台要求上传的，没有就是不能卖，不是"审核松就能过"。**

## 二、知识产权四类风险

| 类型 | 表现 | 自查方法 |
|---|---|---|
| 商标 | 品牌名、Logo、型号名与他人注册商标冲突 | 目的国商标库检索（USPTO/EUIPO/CNIPA） |
| 专利 | 实用专利（结构/功能）、外观专利（造型） | Google Patents + 目的国专利库，按关键词与图检索 |
| 版权 | 卡通形象、图案、摄影图、说明书文案 | 不用来源不明的图；图案类目尤其高危 |
| 商业秘密 | 代工厂泄露他人设计 | 选品时问清模具来源 |

**被投诉后的处理顺序**：
1. 先判断投诉是否成立（对方专利/商标是否有效、是否覆盖你的产品）
2. 成立 → 下架、清库存、改款；不成立 → 通过平台渠道提交不侵权说明（附检索证据）
3. **不要**直接反通知了事，反通知可能引发诉讼，需法律意见后再动

## 三、账号风控的五个维度

| 维度 | 风险点 | 合规做法 |
|---|---|---|
| 网络 | 公共 VPN、频繁跨区登录 | 固定网络环境，专人专机 |
| 设备 | 多店同机、浏览器指纹相同 | 一店一环境 |
| 资金 | 多店共用收款账户 | 一店一收款 |
| 资料 | 法人/地址/电话交叉 | 主体资料独立 |
| 行为 | 互刷、同步上下架、异常改价 | 运营动作自然化，禁止互刷 |

**明确拒绝**：任何"防关联软件""多账号矩阵"用于规避平台规则的方案。这不是技术问题，是违规问题。

## 四、绩效与处罚的应对框架

### 收到警告/下架通知时

1. **读原文**：平台通知里写明了违反的具体条款编号，先读懂是哪一条
2. **定位范围**：是单品、单类目还是全店
3. **收集证据**：检测报告、授权书、进货发票、物流单、整改前后对比图
4. **提交 POA**：根因 → 已采取措施 → 预防机制，三段式，附证据
5. **不要在申诉期继续上架同类问题产品**，会加重处理

### 资金冻结的常见原因

- 账号审核未通过
- 绩效严重不达标
- 侵权投诉累计
- 疑似虚假发货/刷单
- 收款主体与店铺主体不一致

**冻结期通常 90 天起**，期间要保证正常发货与回复，否则会被判永久停用。

## 五、产品安全与召回

| 风险 | 触发 | 应对 |
|---|---|---|
| 产品致伤投诉 | 结构缺陷、电池过热、小零件脱落 | 立即停售、留证据、联系买家、评估召回 |
| 平台强制下架 | 安全投诉达阈值 | 提供检测报告，整改后申请恢复 |
| 监管通报 | 欧盟 Safety Gate、美国 CPSC 通报 | 必须配合，隐瞒会升级为法律责任 |

**儿童产品、带电产品、食品接触产品是三大高危区**，做这些品类必须把认证与测试预算前置。

## 六、合规检查清单（上新前逐项打勾）

- [ ] 目的国是否要求强制认证？证书是否在有效期内、是否覆盖该型号
- [ ] 商标是否在目的国可注册/可使用？品牌名是否已被他人注册
- [ ] 外观是否侵犯他人专利？（做过图形检索）
- [ ] 图片、文案是否原创或已获授权
- [ ] 是否需要 EPR / WEEE / 电池注册号？平台是否已校验通过
- [ ] 标签语言、警示语是否符合目的国要求
- [ ] HS Code 是否确认？申报货值是否真实
- [ ] 儿童产品是否有年龄标识与 CPC/EN71
- [ ] 电池是否有 UN38.3 与 MSDS，物流渠道是否可收
- [ ] 说明书是否含安装/使用/警告三部分

**十项里有一项不确定，就不要上架。** 下架一条链接的损失，远小于扣货与索赔。
